# HighFleet Allies v@PACK_VERSION@

## Shipworks test allies

- **ADD**, beside TEST in the top row, captures the currently edited ship—including unsaved changes—into the ship list.
- **CLEAR**, beside ADD, empties the list without leaving Shipworks or changing the edited ship.
- The existing **FIGHT** button brings the listed ships into test combat as friendly AI allies. Add up to **eight allies**.
- Loading or switching designs, RESET, RETRY, and returning from test combat preserve the list. Leaving Shipworks clears it.
- Buttons match the native Shipworks font/style; ship names use the mod's PLAYER-marker font.

ADD/FIGHT confirmed working in game by the maintainer. CLEAR still needs in-game verification.

## Install

For HighFleet **Steam 1.163** with Modloader v4. Back up `Saves`, extract the ZIP into the game directory, and remove older ally/AI DLLs so only one of each remains. Merge the included configs with your custom settings.
